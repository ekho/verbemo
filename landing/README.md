# Лендинг Verbemo

Двуязычный статический сайт: `/` — английская версия, `/ru/` — русская,
`/privacy/` и `/ru/privacy/` — приватность. Язык выбирается ссылкой в футере.
Домен, nginx, SSH-деплой, аналитический сервер и учётные данные не нужны.
Публичный домен пока не выбран: canonical и абсолютные sitemap URL не заданы.

Локальный просмотр из корня репозитория:

```sh
python3 -m http.server 8765 --directory landing
```

Проверки: `python3 landing/tests/check.py` и существующий браузерный runner
`node landing/tests/browser.cjs` (нужны Playwright и Chromium).
`VERBEMO_PREVIEW_URL` меняет адрес локального сервера, по умолчанию
`http://127.0.0.1:8765`. Runner проверяет EN/RU, обе темы, мобильную ширину,
загрузку ресурсов, собственные ссылки и отсутствие запросов статистики при
просмотре и нажатии кнопок. Статистика сайта отключена.

Кнопки обеих платформ пока ведут на `https://github.com/ekho/verbemo/releases`.
После реального релиза `python3 scripts/update-site-download-links.py landing --public`
проверяет общий manifest, подписанные platform receipts, все байты/хеши и source
тег публичного latest. `--artifacts` принимает полный проверенный каталог общего
релиза для локальной подготовки; это само по себе не доказывает публикацию.
Не запускайте публикацию сайта или каталогов пакетов этими скриптами: они только
меняют локальные файлы.

Страницы показывают реальные macOS-снимки Verbemo 0.1.0 (476), source
`8bc6f6be2bf6d5830dc1f1e8f3b5f122170db942`. Оригинальные JPEG-байты CUA
скопированы без обрезки и обработки; хеши и размеры записаны в
`assets/screenshots/macos/0.1.0-476/provenance.json`. EN/RU используют свой снимок
главного окна; Settings и About доступны из
[отчёта приёмки](../docs/testing/verbemo-independent-releases-acceptance.md).
Запись и обработка при съёмке выключены: снимки не доказывают качество аудио
или расшифровки. Старые снимки остаются историческими ассетами и не используются
страницами; Windows-снимки и фактическая Windows-приёмка отложены.
