# #72 — повторная проверка плотности нативного интерфейса

Пользователь отклонил пустое пространство в расшифровке и бейджи говорящих. Это исправление Mac-пилота в той же ветке эпика, а не пользовательская приёмка #72 или полный аудит всего приложения.

## Причины и исправления

| Дефект | Наблюдение до исправления | Исправление |
|---|---|---|
| Двойной левый отступ | 74 pt от края документа; значок на 36 pt правее названия | Один общий отступ 24 pt; удалён вложенный stack и автоматические table insets |
| Пустота под вкладками | 46.5 pt до первого бейджа | Удалён повторный верхний отступ; проверяется расстояние 0–16 pt |
| Буква прижата кверху | Ошибка центра глифа 10 px в нативном bitmap | Центрирование через NSTextFieldCell; фон заполняет всю область 26×24 pt |
| Одинаковые цвета | Разные голоса имели одинаковый фон | Девять пар из принятой палитры #71; в тёмной теме пара инвертируется |
| Имя посередине длинной реплики | Стек метаданных был центрирован вертикально | Имя и время привязаны к началу реплики |
| Недостаточная высота длинного текста | NSString оценивал 126 pt, настоящий NSTextField требовал 133 pt | Измерение тем же нативным wrapping field; нижний отступ проверяется отдельно |
| Последняя строка у разделителя после появления scroller | При окончательной ширине 1027 pt таблица сохраняла прежнюю высоту 77 pt; текст требовал ещё 19 pt | Повторный расчёт высот по окончательной ширине колонки после layout |
| Полосы после последней реплики | Системная сетка рисовала несуществующие строки | Разделитель только внутри настоящей строки |
| Зазор/перекрытие после resize | В узком окне −19.5 pt, после hide списка 48.5 pt вместо 14.5 pt | Восстановление позиции чтения после layout, без повторного входа в Auto Layout внутри setFrameSize |

Заголовок возвращён к принятым 20 pt; промежутки метаданные → название и название → плеер сокращены. Колонка говорящего 190 pt, зазор перед текстом 16 pt и отступы строки по 10 pt сохранены для читаемости. В узкой колонке метаданные располагаются над текстом.

Цвет обозначает **голос внутри выбранной версии**, не человека. Одинаково сопоставленные A/C сохраняют разные цвета голосов. Порядок — первое появление в версии, включая «Я»; неизвестный голос нейтрален. После девяти цветов палитра повторяется; буква и имя остаются обязательными. Поиск и изменение имени цвет не меняют. Transcript и Participants используют одну палитру. Все 18 пар светлой/тёмной темы проверены на контраст текста не ниже 4.5:1; это не полный аудит системной доступности.

Pixel tests проверяют центр буквы и заполненный угол бейджа; native integration проверяет gutter/ширину/отсутствие перекрытия после wide → narrow → hide → wide. Проверки чтения сохраняют сегмент и offset при переносе строк. Это дополняет GUI-проверку, не заменяет её.

## Изоляция и ограничения

Отдельное приложение `.build/ux72-density/Verbemo Studio Review.app`, ID `name.ekho.verbemo.ux72.density`, профиль `.build/ux72-density/home` через CFFIXED_USER_HOME. Calendar, ASR, live transcription, speaker naming, summary automation, auto-record и MCP выключены. Сборка ad-hoc, не подписанный выпуск.

Windows, VoiceOver, полная keyboard-only проверка, системный масштаб/повышенный контраст/Reduce Motion, runtime macOS 14.2/Intel и физическая слышимость не подтверждены. Пользовательская приёмка остаётся открытой; merge/release не выполнялись.
