# Макет A — проверка и пользовательская приёмка #70

**30.10.2026.** Пользователь выбрал A после сравнения трёх структур. [Автономный макет](prototype-a.html) подготовлен в ветке `codex/67-cross-platform-ux-redesign`; #70 остаётся открытой до приёмки. [Карта функций и переходов](03-structure-and-flows.md).

## Как открыть и что попробовать

Открыть `prototype-a.html` в браузере. Это один файл со встроенными стилями, кодом и синтетическими данными; сборка, пакеты и сервер для использования не нужны. Если встроенный браузер запрещает `file://`, проверочная локальная страница доступна, пока запущен preview: `http://127.0.0.1:18770/prototype-a.html`. Сервер выдаёт только этот HTML на loopback, прочие пути возвращают 404. Самостоятельность файла проверена по встроенным ресурсам и отсутствию сетевых запросов; прямой запуск через `file://` во встроенном браузере не проверен из-за запрета протокола.

Вверху — управление макетом: размер рамки, RU/EN, представление macOS/Windows и сброс. Оно не является частью предлагаемого приложения. Оформление намеренно нейтральное: палитра и компоненты ещё выбираются на #71. Изменения живут в памяти вкладки: повторное открытие встречи их сохраняет, перезагрузка страницы или «Сбросить макет» возвращает исходный набор.

1. В начальной встрече исправить C: Борис → Вера через кнопку у реплики. Проверить понятность области изменения, отменить вторую правку клавишей Escape, снять связь. Сравнить с архивом и с вкладкой участников.
2. Найти «Кварцевый компас» по библиотеке, затем «Сапфировый маяк» внутри встречи. Перейти к совпадению и закрыть поиск. Проверить, понятно ли, где искать и как вернуться к чтению.
3. Открыть длинную встречу, скрыть список, прокрутить текст. Перейти в настройки, найти язык встречи, место обработки и папку записей; вернуться к той же реплике.
4. Установить рамку 760×600 и повторить чтение/назначение. Проверить, хватает ли места и заметен ли возврат к списку.
5. По желанию: начать учебную запись и перейти в настройки; создать новую сводку, выбрать в деталях демонстрационные «Ошибка / Успех» либо отменить. После новой расшифровки проверить сохранённую старую версию и явное открытие нового результата.

Для приёмки нужны замечания к размещению и переходам, а не оценка финальной палитры. Время выполнения, подсказки и ошибки человеком пока не измерялись.

## Что действительно проверено

Проверки выполнены Computer Use в браузере на Mac, по видимым элементам и DOM. Данные — пять встреч из воспроизводимого генератора #69, включая 180 реплик/9 говорящих, неверное назначение, настоящий неизвестный голос и два архива. Ни один из шагов ниже не обращается к настоящей библиотеке Verbemo.

| Сценарий | Результат / предел свидетельства |
|---|---|
| Назначение из расшифровки | C → Вера видна в тексте; Escape сохраняет предыдущее имя; снятие связи возвращает «Говорящий C»; архив не меняется. После Apply фокус возвращается на `edit-turn-2` |
| Неизвестный голос | В интерфейсе объяснена недоступность назначения. Отказ назначения `them ?` отдельно проверен моделью состояния |
| Области поиска | Библиотечные запросы по тексту/сводке находят правильный источник; результат открывает нужную вкладку/фрагмент. «Несуществующий термин» показывает «Нет совпадений», встречи сохраняются. Поиск по названию также проверен моделью |
| Возврат из локального поиска | Расшифровка → совпадение в сводке → закрыть поиск возвращает расшифровку и исходную прокрутку; фокус на кнопке поиска |
| Длинное чтение / настройки | Прокрутка до реплики 180, время 29:50. После настроек восстановлена позиция `scrollTop=22167.5` в этой рамке; это координата проверки, не продуктовая гарантия пиксельного значения |
| Версии при навигации | Выбранный архив планирования сохранился после перехода к другой встрече и возврата через библиотеку |
| Повторная расшифровка | Успех сохраняет предыдущий текущий результат как отдельный архив и оставляет его выбранным. «Открыть новый результат» явно переключает на новую текущую версию |

| Удаление | Cancel сохраняет встречу; Delete → Undo возвращает её. Это операции над памятью макета, не проверка файловой системы/корзины |
| Клавиатура | ⌘F и Ctrl+F фокусируют поиск в открытой встрече; Escape закрывает редактор/поиск. Физическая русская раскладка и полный обход всех действий клавиатурой отдельно не проверены |
| Размеры и локализация | Внешние CSS-рамки 1340×848 и 760×600; клиентская область на 2 px меньше из-за рамки. У минимального Mac-вида область чтения около 327 px по высоте; горизонтального переполнения текста не обнаружено. Проверена выборка RU/EN, light/dark, не все сочетания всех действий |

## Проверки модели и независимый просмотр

`node docs/ux/redesign-2026-10/prototype-a.test.cjs` — **9/9 PASS**. Проверяются состав синтетических данных, источники/области поиска, назначения и их изоляция, отказ неизвестному/stale/busy, сохранение сводки при ошибке/отмене, привязка задания к встрече при навигации, delete/undo и сохранение старой версии при успешной повторной расшифровке. Первый запуск остановился на отсутствии артефакта; дополнительная проверка повторной расшифровки сначала выявила потерю старой версии, затем прошла после исправления.

Независимый read-only просмотр выявил шесть ошибок первой версии: сброс архива при возврате, неполный возврат из поиска, потерю старого результата после повторной расшифровки, потерю фокуса после назначения, сброс прокрутки списка при переходе в настройки, возможность запускать сводку текущего результата из контекста архива. Повторный просмотр оценил все шесть как исправленные. Это ограниченная проверка перечисленных исправлений; она не доказывает отсутствие любых иных проблем.

## Ограничения

Это демонстрация структуры: звук, запись, модель, поиск пользовательских файлов и долговременное сохранение не реализованы. Импорт добавляет вымышленную встречу; системные диалоги, календарь, модели, токены MCP, меню ОС, внешний редактор, экспорт, обновления и installer показаны в карте функций или объяснены как границы макета. Здесь нет новой реализации продукта и нет решения о SwiftUI/AppKit.

Поиск по всей библиотеке использует только текущие результаты; поиск внутри встречи — выбранную версию. Поиск по всем архивам остаётся отдельным вопросом объёма. Демонстрация повторной расшифровки использует учебный текст, а не реальный результат модели.

Нет человеческого baseline, проверки новичком, VoiceOver, нативного фокуса/масштабирования, системной клавиатуры или Windows GUI. Назначения сохраняются при навигации внутри вкладки, но сбрасываются при её перезагрузке. Некоторые уже показанные уведомления сохраняют язык момента их появления. Нейтральная тема не утверждает дизайн-систему.
