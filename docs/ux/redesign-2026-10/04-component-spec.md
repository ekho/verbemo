# «Студия»: спецификация компонентов — #71

**30.10.2026.** Визуальная основа принята пользователем. Этот документ завершает правила для ограниченного пилота; нативная реализация и её приёмка ещё не выполнены. История выбора и браузерные свидетельства находятся в [04-visual-system.md](04-visual-system.md). Предлагаемый объём — [05-native-pilots.md](05-native-pilots.md).

## Цвет, шрифт и плотность

Ниже — продуктовые значения выбранного макета. В нативном UI размеры задаются в macOS points / WPF device-independent units и проверяются на экране; CSS px не являются нормативом ОС. Системные контрастные настройки имеют приоритет над палитрой.

| Роль | Светлая | Тёмная | Применение |
|---|---|---|---|
| Reading | `#FFFFFF` | `#1C2532` | Текст расшифровки и сводки |
| Surface | `#E9EDF1` | `#141D29` | Навигация, плеер, служебные панели |
| Text | `#172B3B` | `#EDF3FA` | Основной текст |
| Secondary | `#475D6B` | `#AEBBCD` | Дата, время, пояснение |
| Accent | `#294D9B` | `#9BBCF5` | Действие, активная вкладка, фокус |
| Selection | `#DBE4F4` | `#2F405C` | Выбранная встреча |
| Separator | `#C3CED7` | `#405169` | Декоративное разделение; не единственный признак контрола |
| Hover | `#E5EAF3` | `#28364A` | Наведение, без изменения выбранной строки |
| Search mark | `#F1DB91` | `#665823` | Найденный текст; текущее совпадение дополнительно обведено |

Ошибки, успех, предупреждение, запись и disabled используют смысловые системные цвета с иконкой/текстом. Они не получают произвольную общую RGB-палитру. Цвет говорящего — дополнительный ориентир: буква и имя сохраняются при отключении цвета. В пилоте цвета бейджей брать из макета с проверкой всех реально использованных пар; неподтверждённые пары заменить контрастным нейтральным бейджем, сохранив букву.

Системный шрифт: macOS system; Windows системный шрифт сообщения, с проверкой фактического отображения. Базовые размеры: текст реплики 15, заголовок встречи 20, основной интерфейс 14, подписи 12. Интервал строки реплики около 1.6, без фиксированной высоты абзаца. Интервалы: 4/8/12/16/24/32. Нативные поля, меню и фокус сохраняют системное поведение.

Ориентиры компоновки: библиотека 264, колонка говорящего 190, расстояние до текста 16, отступ реплики сверху/снизу 10. Обычная кнопка с иконкой без текста — зона 34×34; карандаш 26×26. Это исходные минимумы пилота, которые можно увеличивать для нативного фокуса и крупного текста. Имя переносится; кнопка не исчезает при наведении. Не сжимать текст ради точного повторения ширины макета.

## Компоненты и обязательные состояния

| Компонент | Обычное состояние | Остальные состояния и поведение |
|---|---|---|
| Панель действий | Новая запись — основная кнопка; импорт и настройки — иконка + текст; управление списком | Нативные операции и их ограничения сохранены. При нехватке места перенос/меню с названиями, без недоступных действий за краем |
| Список встреч | Название, дата/длительность, значок состояния; выбранная встреча отличается от hover | Клавиатурный фокус виден отдельно от selection; неактивное окно не теряет selection; пустая библиотека объясняет запись/импорт; нет результатов предлагает очистить фильтр |
| Статус встречи | Готово — check; ожидание — clock; обработка — arrows/progress; ошибка — warning; запись — record; пауза — pause; отменено — cancelled | Tooltip и доступное имя описывают статус словами. Два состояния не различаются только цветом. Подробности/ошибки остаются текстом в деталях и нижней строке |
| Шапка встречи | Заголовок, выбранная версия, детали, постоянно видимое поле поиска | Нет готовой версии — объяснение, поиск недоступен с причиной. Архив явно назван; загрузка новой версии не выдаёт старый текст за новый |
| Вкладки | Расшифровка / Сводка / Участники; selected обозначен линией и состоянием доступности | Фокус и selected независимы. Переключение сохраняет позицию чтения каждой вкладки; названия не обрезаются при RU/EN |
| Реплика | Слева буква/имя/карандаш и время; справа выделяемый текст | Длинные имена переносятся. Unknown имеет `?` и пояснение, без ложного назначения. Отсутствие аудио выключает переход по времени, текст остаётся читаемым. Пустая расшифровка и ошибка чтения — разные сообщения |
| Назначение говорящего | Карандаш открывает редактор существующих календарных участников и ручного имени | Показать голос и область «Все реплики этого говорящего в выбранной версии». Сохранить/Отмена; повторное сохранение заблокировано на время операции. Ошибка оставляет ввод и возможность повторить, отмена ничего не пишет. Фокус возвращается к тому же карандашу |
| Поле поиска | Placeholder и постоянное доступное имя; область обозначена в шапке | При запросе: число, текущее совпадение, следующий/предыдущий, очистка. Ноль результатов — текст, не ошибка. Пустой запрос убирает подсветку и навигацию. Ошибка чтения источника показана отдельно от «ничего не найдено» |
| Плеер | Play/Pause, отдельный Stop, позиция/длительность, seek, скорость и громкость | Play продолжает; Pause сохраняет позицию; Stop ставит 0; повтор после конца начинается с 0. Loading и ошибка аудио объясняются текстом. Скорость и громкость текущего приложения не теряются из-за их отсутствия в макете |
| Детали | Кнопка только с иконкой панели и tooltip | Открытие не меняет встречу/версию. Escape/закрыть возвращают фокус к кнопке. Длинные сведения прокручиваются; существенные ошибки не скрыты только внутри панели |
| Настройки | Категория; подпись, значение, пояснение; связанные поля рядом | Секреты замаскированы; ошибка около поля; отключённая настройка объясняет причину. Загрузка/проверка блокирует повтор операции, не весь экран. Состояние подключения отдельно от выбранного провайдера. Применяется при внедрении настроек в #73 |
| Меню/диалог | Системные меню, sheet/dialog; действия с понятными именами | Enter применяет только валидное действие, Escape отменяет безопасное редактирование. Destructive действие не получает default focus. Ошибка не закрывает ввод; возврат фокуса обязателен |
| Запись/обработка | Постоянная нижняя строка, имя операции и состояние словами | Навигация и поиск не перезапускают/не останавливают операцию. Пауза отличается от записи. Сохранённый результат остаётся читаемым. Показывать только реально поддержанные действия отмены/повтора |

Для всех действий: иконка + текст; исключения без видимого текста — Play/Pause, Stop, детали, закрытие и карандаш. Навигационные вкладки/категории и строки списка не превращаются в набор кнопок действий. Иконка декоративна для screen reader, доступное имя одно и локализовано; Play/Pause меняет имя вместе с действием. macOS — системные символы при наличии в минимальной ОС, Windows — доступные в приложении векторные иконки. Новая библиотека иконок не требуется.

Default, hover, pressed, focus, selected, disabled и busy не подменяют друг друга. Hover меняет поверхность, pressed даёт краткую обратную связь, keyboard focus — системное кольцо/контур, selected сохраняется после ухода фокуса. Disabled блокируется программно, busy сообщает выполняемое действие. Никаких исчезающих при наведении важных кнопок. Reduce Motion отключает необязательное движение; прогресс всегда имеет текстовый эквивалент.

Уведомление об обработке имеет крестик «Скрыть уведомление об обработке» справа в заголовке. Закрытие скрывает только этот блок: состояние/результат и доступ через нижнюю строку/детали сохраняются. Новое задание или новый статус показывают блок снова; после закрытия фокус возвращается к заголовку встречи. Кнопки создания новой сводки и версии расшифровки используют значок соответствующего содержимого со значком обновления поверх правого нижнего угла, вместе с текстовым названием действия.

## Поиск и контекст

Полный продукт: поле библиотеки ищет по названиям, расшифровкам и сводкам; поле встречи — только по расшифровке и сводке выбранной версии. Дублирующая кнопка библиотеки в toolbar удалена. При скрытом списке его возврат открывает поле библиотеки.

**Пилот #72:** реализовать настоящий поиск внутри выбранной версии. Библиотека пока сохраняет существующий фильтр и честную подпись «Название встречи». Индекс всей библиотеки, его обновление при переназначении/новой версии и поиск в настройках — отдельный сценарий #73, не фальшивые результаты в пилоте.

Запрос — буквальная подстрока без учёта регистра, без regex, морфологии и смыслового поиска; пробелы по краям игнорируются. Совпадения идут по репликам, затем по видимому тексту сводки; markdown-разметка не участвует. ⌘F/Ctrl+F фокусирует поле встречи; Enter/Shift+Enter — следующее/предыдущее совпадение с циклом. Клик результата переводит к тексту, не запускает аудио. Подсветка не уничтожает выделение/копирование.

При первом непустом запросе запомнить встречу, версию, вкладку и позицию; смена запроса не перезаписывает эту точку. Очистка/Escape восстанавливает её и оставляет фокус в поле. Явная смена встречи/версии завершает старый поиск, поэтому последующая очистка не возвращает пользователя в старую встречу. Обновление назначения в той же версии сохраняет контекст и позицию. Возврат из настроек также сохраняет выбранную встречу/версию. Позиция хранится как реплика/символ + относительный отступ, а не один scrollTop, чтобы перенос строк не ломал возврат.

## Адаптация и доступность

Широкое окно: список + встреча. Узкое: один основной блок с явным возвратом. Колонка говорящего становится шапкой реплики, когда имя и текст перестают помещаться; перенос определяется доступным местом и размером текста. Браузерные пороги 900/590 — свидетельство макета, не обязательные нативные breakpoint.

При 150–200% текста шапка не должна занимать всю область чтения: она прокручивается вместе с содержимым. Не повышать существующий минимум окна или macOS 14.2 ради вёрстки. Минимальные рамки для проверки: Mac 760×600, Windows 820×520. Системный DPI и размер текста тестируются отдельно. Клавиатурный путь: список → версия → поиск → вкладки → плеер → реплики/назначение → детали; скрытые области исключены из обхода.

Текст — не менее 4.5:1 в обычных темах; значимые контуры/иконки — цель не менее 3:1. Системные высококонтрастные режимы проверяются отдельно, декоративные разделители не выдаются за интерактивные границы. Native VoiceOver/Narrator должен читать имя говорящего, время, область назначения, выбранную версию и статус действия. Весь сценарий доступен клавиатурой; drag/цвет/анимация не единственный способ действия.

Основания: [Apple designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos/), [Microsoft accessible text](https://learn.microsoft.com/en-us/windows/apps/design/accessibility/accessible-text-requirements), [WPF automation properties](https://learn.microsoft.com/en-us/accessibility-tools-docs/items/wpf/control_automationproperties). Числа плотности выше — решения продукта, не требования этих документов. [NSHostingView](https://developer.apple.com/documentation/swiftui/nshostingview) позволяет встраивать SwiftUI в существующую AppKit-иерархию; предлагаемый выбор границы обоснован отдельно в пилоте.
