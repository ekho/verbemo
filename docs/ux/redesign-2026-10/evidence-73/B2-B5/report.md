## Решения исполнителя и цена ошибки

1. Старые проверки «список встреч остаётся в настройках» заменены принятой структурой категорий/явного возврата. Цена: к встречам возвращаются отдельной командой.
2. Общие Studio-токены применены к существующему AppKit; SwiftUI остаётся в шапке встречи. Цена: дальнейшее сопровождение AppKit-layout.
3. MCP использует полную ширину узкой страницы; проверяются реальные границы окна вместо прежних520pt. Цена: более длинные строки в широком окне.
4. Сначала Debug667 preflight, затем финальный Universal670, с разными хешами/метками. Цена: Debug сам по себе не проверяет оптимизированную сборку; финальный GUI проведён отдельно.
5. Windows исключена из этого ревью по поручению пользователя. Цена: её поведение остаётся непроверенным до75–77.
6. Реальные capture/inference/календарные разрешения/модели/update не запускались ради UI. Цена: hardware/provider-сбои могут проявиться в74.
7. Полная доступность и runtime14.2/Intel остаются74. Цена: соответствующие дефекты могут ещё существовать.
8. Решения B1 о32MiB и чтении по запросу сохранены. Цена: большие материалы не ищутся, повторный поиск требует I/O.
9. Build/tests/GUI устанавливаются свидетельствами исполнителя, отдельно от ревью чтением кода. Цена: одно ревью не доказывает runtime-поведение.
10. Завершающий валидатор использует свежие source-pinned test/build/GUI-артефакты без повторного полного прогона ради документации. Цена ошибки старого результата ограничена проверками source, хешей пакета/логов/снимков/данных.

Отложенных Minor-находок ревью нет.
