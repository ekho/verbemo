# #73 macOS B1 — библиотечный поиск

**01.11.2026. B1 проверена; #73 остаётся открытой для B2–B5.** Продуктовый источник `d738306edd2897536b6c0b9c6258393c5347c852`, Verbemo0.17.2 Review660. [Manifest](verification.json), [результат полного прогона и пропуски](test-summary.txt), [ревью и исправления](review.md).

## Результат

Библиотека ищет по названию, папке, дате, приглашённым, текущей расшифровке и актуальной сводке. В строке результата видны источник и двухстрочный фрагмент; найденная фраза помещается в проверенной узкой колонке. Выбор содержательного результата открывает текущую версию, нужную вкладку и локальное совпадение. Старый хеш или сводка прежней расшифровки не принимаются за текущий результат.

Архивный текст остаётся доступным локальному поиску выбранной версии. Обновление выдачи сохраняет выбранную встречу, архивную версию, локальный поиск и место чтения, если соответствующий контекст сохранился; настройки не получают скрытый активный выбор встречи. Отсутствие записей, пустой фильтр, нулевой запрос, поиск в процессе и неполная проверка материалов различаются.

Поиск не запускает обработку и не записывает материалы. Глобальный постоянный индекс, новые настройки и зависимости не добавлены.

- Два существенных замечания свежего read-only ревью воспроизведены RED→GREEN: потеря контекста content-only результата и сводка прежнего поколения после настоящего `TranscriptVersions.commit`. Полный прогон дополнительно поймал возврат из настроек на неправильную версию; исправлен в том же проходе.

## Проверка принципов Apple Design в границах B1

| Принцип | Вердикт и основание |
|---|---|
| Purpose | Соответствует: поиск и переход обслуживают согласованные задачи чтения встреч. |
| Agency | Соответствует: запрос/фильтр сбрасываются, поиск обратим и не изменяет материалы. |
| Responsibility | Соответствует: локальные чтения, явная неполнота при ошибке,430 файлов не изменены. |
| Familiarity | Соответствует: native search field, таблица, popover-фильтр, версия и вкладки. |
| Flexibility | Соответствует в проверенной части:760/1340pt и колонка220/400; полная проверка доступности остаётся #74. |
| Simplicity | Соответствует: один источник/фрагмент на встречу, два видимых ряда текста, общий сброс. |
| Craft | Соответствует в проверенной части: реальное измерение высоты, Unicode и переход к нужному материалу; известные последующие пункты ниже. |
| Delight | Не применимо: отдельные декоративные эффекты для поиска не требуются. |

Новое поле поиска имеет native высоту32pt, подпись фрагмента12pt; ограничение в две строки измеряется native line height. Контраст всех системных пользовательских акцентов, VoiceOver, полный keyboard-only, системный текст150/200%, повышенный контраст и Reduce Motion **не квалифицированы** этой проверкой.

## Решения и оставшиеся границы

- Материалы читаются по запросу в фоне без постоянного индекса и полного каталога текстов в памяти. Цена: повторное фоновое чтение вместо мгновенного кэшированного поиска.
- Нерегулярные/связанные файлы и материалы более32MiB не принимаются; результат обозначается неполным. Цена: слишком большой материал пока нельзя найти по содержимому.
- Ревью охватывает всю B1 от3c4707b; ранее принятый #72 не пересматривается автоматически. Цена: существующий дефект вне изменённого пути может остаться до #74.
- GUI-уточнения сначала проверялись в Debug-кандидате, затем повторены в универсальной сборке того же источника. Различие типов и хешей сохранено; это не доказывает все возможные различия оптимизаций.
- Завершающий валидатор проверяет свежий полный прогон, текущий исходный код, пакет, хеши данных и снимков. Повторять весь прогон только ради записи в журнал не требуется; цена ошибки старого свидетельства ограничена проверками источника/хешей.

До закрытия всей #73 остаются B2–B5. В B5 также учтены иконка общей кнопки сброса и очистка старого tooltip заголовка пустой встречи. Нативная итоговая пользовательская/платформенная приёмка #74 не выполнена. Runtime macOS14.2/Intel, физический звук, настоящая обработка, установщик/обновление и Windows #75–#77 остаются непроверенными. Merge и выпуск не выполнялись.
