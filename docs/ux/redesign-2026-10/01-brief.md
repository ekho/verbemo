## Ограничения платформ

Сведения ниже проверены по исходникам и документации на основании ветки; это не проверка работающих приложений.

| Область | macOS | Windows |
|---|---|---|
| Текущий UI | AppKit; SwiftUI разрешён для выбранных частей | C#/WPF, подтверждено `UseWPF` в проекте |
| Текущий порог платформы | macOS 14.2 в `Package.swift` | Windows 11 24H2 x64 по README; target `net10.0-windows10.0.26100.0` |
| Проверка нативного поведения | Отдельная проверка Mac | Отдельная проверка Windows после подтверждения доступности хоста |

Источники: [README](../../../README.md), [Package.swift](../../../Package.swift), [Windows project](../../../windows/src/Verbemo.App/Verbemo.App.csproj). Поднимать системные требования без отдельного решения нельзя.
