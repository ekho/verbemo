# Сопоставление участников: стабильная ширина и полные варианты

Пользователь сообщил о разной ширине пустого, короткого и сопоставленного поля и обрезанных вариантах. Старый компонент задавал только диапазон120–360pt, оставляя предпочтительную ширину зависимой от значения. Регрессия воспроизведена до исправления: различия до240pt, три нарушения на двух доступных ширинах.

Общий SpeakerAssignmentChoice теперь предпочитает360pt, сжимаясь при недостатке места. Одинаковый компонент используется во вкладке участников и редакторе из расшифровки. Поле остаётся нативным редактируемым NSComboBox. Прозрачная кнопка поверх стрелки и команды вверх/вниз открывают NSMenu с полными строками и текущим отмеченным вариантом. Меню имеет минимум ширины поля и расширяется по содержимому: [правило NSMenu.minimumWidth](https://developer.apple.com/documentation/appkit/nsmenu/minimumwidth). Приватные методы AppKit не используются.

Выбор сохраняется после завершения отслеживания меню; Escape не назначает подсвеченного участника. Ручное имя, ошибки/повтор, Apply/Cancel редактора расшифровки и guards недоступности сохранены. Нативная AX-ячейка поля сохранена, кнопка доступна напрямую, без лишней группы. Очистка AX-владельцев скрытых окон NSComboBox сохранена для предотвращения прежнего сбоя при освобождении редактора.
