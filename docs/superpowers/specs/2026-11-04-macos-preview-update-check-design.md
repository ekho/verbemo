# Проверка обновлений macOS Preview

Пользователь macOS Preview может узнать о новой версии в Verbemo и скачать её DMG через браузер по кнопке «Скачать». Установка остаётся ручной.

## Источник релизов

Используем публичный список релизов `ekho/verbemo` на GitHub. В нём уже есть признак Preview и ссылки на файлы. Отдельный канал публикации потребовал бы дополнительного файла и изменений в выпуске релизов. Стабильный канал Sparkle предназначен для подписанных сборок.

Проверка включается явной меткой в `Info.plist`, которую ставит сборка Preview. Проверяем опубликованные prerelease с тегом `verbemo-v<VERSION>` и загруженным файлом `Verbemo-<VERSION>-macos-universal.dmg`. Выбираем наибольшую версию численно по компонентам SemVer и предлагаем её только если она новее установленной. Для кнопки принимаем прямой HTTPS-адрес ожидаемого файла релиза в `ekho/verbemo`.

## Поведение

- Пока Verbemo запущен, фоновая проверка выполняется раз в 24 часа. Время последней автоматической попытки сохраняется между запусками. При старте приложение проверяет сразу, если попыток ещё не было или интервал истёк.
- Кнопка «Проверить обновления…» в разделе «О программе» запускает проверку сразу. Ручная и фоновая проверки используют один текущий запрос, если совпали по времени.
- Новая версия отображается в «О программе» с номером и кнопкой «Скачать». Фоновый результат появляется там же без всплывающего окна. Ручная проверка сообщает, если обновлений нет или проверку не удалось выполнить.
- «Скачать» передаёт прямую ссылку браузеру по умолчанию. Verbemo продолжает работу, а пользователь сам решает, когда устанавливать скачанную версию.

## Проверка

Проверить выбор версии и DMG, ручной запрос в пределах 24 часов, расписание после перезапуска и наличие метки только в Preview. В собранном macOS Preview пройти сценарий от «О программе» до начала загрузки DMG в браузере. Проверить, что ручной запрос при недоступности GitHub показывает ошибку.
