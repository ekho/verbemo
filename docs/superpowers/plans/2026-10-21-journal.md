# Journal implementation plan

**Goal:** Apply the approved Journal design to the native macOS app and explicitly track unsupported controls.

**Architecture:** Retain AppKit controllers and processing callbacks. Move the existing library list into the persistent sidebar and compose its existing detail views into a document and inspector. Shared Journal colors/type/placeholder controls only where reused.

**Tech Stack:** Swift 6, AppKit, Swift Testing; existing SwiftPM dependencies.

**Spec:** [Native Journal interface](../specs/2026-10-21-journal-design.md)

**Global Constraints:** No user recordings/configuration touched by verification; no releases; no Windows changes; no fake signal or attribution; preserve all current result and data-loss guards.

**Review Focus:** Navigation during recording (RecordingWorkspaceTests); selection and version retained through settings (JournalWorkspaceTests); narrow inspector and theme layout (JournalWorkspaceTests plus native GUI); exact unavailable messages (JournalWorkspaceTests); existing copy/retranscription/name/delete guards (current regression suites).
