## Limits

This does not establish real microphone/system-audio capture, long-session stability, cloud/local-model processing, a fresh calendar permission flow, end-to-end event linkage during capture or a VoiceOver session. Live-view state and unavailable meters were verified with synthetic UI tests, not a real recording. No Windows host check, installation over the user's app, merge or public release was performed.
