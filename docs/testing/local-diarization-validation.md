# Local diarization validation

[Imported dated results](../history/amanu-local-diarization-validation.md) retain
original archive names, hashes, tests and limitations. They establish only what
those exact Amanu builds exercised, not acceptance of the current Verbemo build.

Use [the current evaluation procedure](local-diarization-evaluation.md) for new
results and record exact source, app/model hashes, corpus and runtime platform.
No private meeting is required for ordinary build or UI validation.
