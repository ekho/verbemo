## Final review and accepted Windows limitations

Whole-branch review at `491040e` found no Critical issue and one Important issue:
the Windows audio idle timer begins after file opening/reading and covers only
response writes. Stalled storage can therefore leave an HTTP request waiting.
The review also found a completed-task tracking leak in the Windows bridge and
synthetic credential assertions that could print test tokens on failure. No
production credential leak was established. These findings remain unresolved.
