# macOS tray menu — 2026-10-22

Base: `16abde3` (Verbemo 0.7.3). These are local working-tree checks;
published release and CI results are recorded separately in the pull request.

Idle order: Start recording, Import recording, Automatic meeting recording,
separator, Settings, Open Verbemo, separator, Quit Verbemo. The recording block
appears only while recording or paused, with elapsed time and Pause/Resume and
Finish recording commands. Routine auto-record decisions no longer occupy the
menu; permission, retry and stop-limit notices remain available.

The recording commands use ordinary native menu items. A horizontal custom-view
prototype was rejected during Computer Use because arrow/Tab navigation skipped
its buttons. Native items preserve standard keyboard selection and accessibility.

Open folder is in Storage settings. Check for updates is on About when this app
supports updates. Processing status opens its exact meeting, clears library
filters, and falls back to Finder if the meeting is outside the current library.

## Limits

Synthetic state checks establish the menu's rendering and command dispatch,
not real-call audio or automatic call detection. Spoken VoiceOver, physical
Intel hardware and Windows GUI were not tested. Windows sources are unchanged.
The common release workflow must independently test/build both platforms before
publishing an unsigned preview; local ad-hoc builds are not a signed release.
